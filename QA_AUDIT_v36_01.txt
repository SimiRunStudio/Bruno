CHANGES IN v36.01
-----------------
1. Corrected frontend document title/version marker to v36.00 so the visible version no
   longer contradicts backend/package release metadata.
2. Fixed live transcript streaming display: partial input/output transcript deltas are now
   accumulated instead of replacing earlier words on every delta. Completed transcript
   events reset their respective draft buffers and are committed to the caption history.
3. Added support for the documented conversation.item.input_audio_transcription.delta
   event while retaining the app's existing compatibility event handling.
4. Reset partial transcript buffers on session start and cleanup to prevent fragments from
   a previous session leaking into the next session.
5. Rewrote stale README files that referenced v33/v34/v35-era documents and missing files.
   Current instructions now consistently describe v36.00 frontend/backend features,
   setup, HTTPS/microphone requirements, API key safety, usage billing and actual limits.
6. Added repeatable frontend syntax/duplicate-ID check and a Node built-in HTTP smoke test.
7. Added npm run check and npm test scripts; package release metadata is 36.1.0.
