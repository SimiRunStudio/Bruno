ASMARON LANGUAGE ACADEMY v36.06 — DEEP POLISH / ONLINE HARDENING
===============================================================

BASE
----
Built from v36.05 online-AI build. Existing UI, offline lesson engine, learner progress,
AI Studio, recorded transcription and GPT-Live WebRTC workflow are retained.

CHANGES IN v36.06
-----------------
1. Restricted static-file serving to index.html and /assets/* only. Backend source,
   environment templates, dotfiles, project metadata and hidden paths are no longer served.
2. Added strict backend URL validation in Settings: HTTPS required for remote hosts;
   HTTP is permitted only for localhost development. Credentials, paths, query strings
   and fragments are rejected.
3. Fixed automatic AI connection status so the first health-check result is reflected
   immediately in the visible UI without requiring a manual rerender.
4. Cached provider model-metadata health checks for 60 seconds to avoid repeated external
   model-list requests during refreshes while keeping health status fresh.
5. Reserved Live session capacity before reading the SDP request body to prevent concurrent
   requests from racing past the configured session-creation cap.
6. Added ISO-639-1 language hint to GPT-Transcribe and expanded accepted browser recording
   MIME types to include OGG and WAV aliases.
7. Set GPT-Live delegated Responses model default to gpt-5.6-terra, matching the current
   official GPT-Live WebRTC example. Main AI Responses model remains gpt-6.1-terra.
8. Raised documented Node.js minimum to 22.6 to match the current official GPT-Live WebRTC
   Node runtime guidance. Render uses Node 22.
9. Expanded automated HTTP security tests for source/dotfile denial and public asset access.

ONLINE AI CONNECTION

---------------------------------
